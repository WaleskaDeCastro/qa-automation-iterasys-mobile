# 🚀 Automação de Testes E2E - Plataforma Iterasys (LearnWorlds)

Este repositório contém a suíte de testes automatizados End-to-End (E2E) desenvolvida para validar os fluxos críticos de negócio, usabilidade e funcionalidades da plataforma de ensino da Iterasys. O projeto utiliza **Playwright** em conjunto com **Cucumber (BDD / Gherkin)** e o padrão arquitetural **Page Object Model (POM)**.

---

## 🛠️ Tecnologias Utilizadas

* **[Playwright](https://playwright.dev/)** – Framework moderno para automação mobile rápida e confiável.
* **[Cucumber.js](https://cucumber.io/)** – Implementação de BDD (Behavior-Driven Development) utilizando a linguagem Gherkin em português (`# language: pt`).
* **JavaScript (Node.js)** – Linguagem base do projeto.
* **Page Object Model (POM)** – Organização de código para reuso e manutenibilidade.
